# 미리봄 행동 그림 파일

완성한 그림을 이 폴더에 PNG로 넣으면 화면과 PDF에 자동으로 표시됩니다.

- `COLONOSCOPY.png` - 대장 내시경 검사
- `GASTROSCOPY.png` - 위 내시경 검사
- `GASTRECTOMY_HISTORY.png` - 위 수술 경험
- `STOP_EATING.png` - 음식 먹지 않기
- `NO_WATER.png` - 물 마시지 않기
- `EAT_PORRIDGE.png` - 흰죽 먹기
- `TAKE_MEDICINE.png` - 약 먹기
- `ASK_DOCTOR.png` - 의료진에게 물어보기
- `TAKE_BOWEL_PREP.png` - 장을 비우는 약 먹기
- `NO_DRIVING.png` - 운전하지 않기
- `COME_WITH_GUARDIAN.png` - 보호자와 함께 오기
- `HOSPITAL_ARRIVAL.png` - 병원 도착
- `CALL_HOSPITAL.png` - 병원에 전화하기
- `CHECK_TEETH.png` - 흔들리는 치아 확인
- `CHECK_TIME.png` - 예약 시간 확인

권장 규격: 1024×1024 PNG, 단색 또는 흰 배경, 굵고 단순한 선, 한 그림에 한 행동, 글자 없는 그림.
